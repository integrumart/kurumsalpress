# Kurumsal Press - Modern WordPress Kurumsal Teması

Modern, şık ve profesyonel bir WordPress kurumsal teması. İşletmeniz için güçlü ve özelleştirilebilir bir çözüm.

## 🎨 Özellikler

### Modern Tasarım
- ✨ Gösterişli gradient tasarım
- 🎯 Profesyonel ve kurumsal görünüm
- 📱 Tam responsive (mobil uyumlu)
- ⚡ Hızlı ve optimize edilmiş
- 🎨 Kolay özelleştirilebilir

### İçerik
- Hero bölümü ile etkileyici karşılama
- Hizmetler showcase alanı
- Blog sistemi
- Widget desteği
- Menü sistemi

## 📦 Kurulum

1. Tema dosyalarını WordPress'in `/wp-content/themes/kurumsalpress` dizinine yükleyin
2. WordPress yönetim panelinden Görünüm > Temalar bölümüne gidin
3. "Kurumsal Press" temasını etkinleştirin
4. Görünüm > Özelleştir ile temayı özelleştirin
