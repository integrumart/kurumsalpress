# Changelog

All notable changes to the Kurumsal Press WordPress theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-02

### Added
- Initial release of Kurumsal Press theme
- Modern and stylish corporate design with gradient color scheme
- Fully responsive layout (mobile, tablet, desktop)
- Hero section with customizable content
- Services showcase section with 6 default service cards
- Complete WordPress theme structure:
  - index.php (main template)
  - single.php (single post)
  - page.php (page template)
  - archive.php (archive listings)
  - search.php (search results)
  - 404.php (error page)
  - header.php and footer.php
  - sidebar.php
  - comments.php
- Template parts:
  - content.php (post content)
  - content-page.php (page content)
  - content-none.php (no results)
- Widget areas:
  - Sidebar widget area
  - 4 footer widget areas
- Navigation menus:
  - Primary menu (header)
  - Footer menu
- Theme features:
  - Custom logo support
  - Custom header support
  - Custom background support
  - Featured image support
  - Post thumbnails with custom sizes
  - HTML5 markup support
  - Responsive embeds
  - Editor styles
- JavaScript functionality:
  - Mobile menu toggle
  - Smooth scrolling for anchor links
  - Back to top button
  - Scroll-based animations
  - Header scroll effects
- CSS features:
  - CSS Grid and Flexbox layouts
  - CSS variables for easy customization
  - Smooth transitions and animations
  - Hover effects on cards and buttons
  - Professional gradient designs
- Comprehensive documentation:
  - README.md (overview)
  - README-THEME.md (detailed documentation)
  - INSTALLATION.md (installation guide)
  - CHANGELOG.md (version history)
- SEO-friendly structure
- Translation ready (Turkish support included)
- Search form template
- Pagination support
- Comment system support
