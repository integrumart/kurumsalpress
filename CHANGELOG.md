# Changelog

Tüm önemli değişiklikler bu dosyada belgelenecektir.

Format [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) standardına dayanır,
ve bu proje [Semantic Versioning](https://semver.org/spec/v2.0.0.html) kullanır.

## [1.0.0] - 2026-01-02

### Eklenenler
- İlk tema sürümü
- Modern ve gösterişli kurumsal tasarım
- Responsive tasarım (mobil, tablet, desktop)
- Hero bölümü ile dinamik ana sayfa
- Hizmetler (Services) özel içerik tipi
- Takım (Team) özel içerik tipi
- 4 widget alanı (Sidebar, Footer 1, 2, 3)
- 2 menü konumu (Primary, Footer)
- WordPress Customizer entegrasyonu
  - Hero bölümü ayarları
  - İletişim bilgileri
- Modern animasyonlar ve hover efektleri
- Gradient renkler ve gölge efektleri
- JavaScript özellikleri:
  - Mobil menü toggle
  - Smooth scroll
  - Back to top butonu
  - Scroll animasyonları
  - Header scroll efekti
- Template dosyaları:
  - index.php (Ana template)
  - single.php (Tekil yazı)
  - page.php (Sayfa)
  - archive.php (Arşiv)
  - search.php (Arama)
  - 404.php (Hata sayfası)
  - comments.php (Yorumlar)
  - searchform.php (Arama formu)
- Özel görsel boyutları
- SEO dostu yapı
- Erişilebilirlik desteği
- Çeviri hazır (i18n)
- Kapsamlı dokümantasyon

### Teknik Detaylar
- WordPress 5.0+ uyumlu
- PHP 7.4+ uyumlu
- HTML5 & CSS3
- Vanilla JavaScript (No jQuery)
- CSS Grid & Flexbox
- CSS Custom Properties (Variables)
- Intersection Observer API
- Gutenberg editör desteği
