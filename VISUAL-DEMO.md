## 🎬 Animasyon Örnekleri

### Sayfa Yüklenme
```
1. Hero içeriği: Fade in (1s)
2. Service kartları: Fade in up (kademeli)
   Card 1: 0.1s gecikme
   Card 2: 0.2s gecikme
   Card 3: 0.3s gecikme
   Card 4: 0.4s gecikme
   Card 5: 0.5s gecikme
   Card 6: 0.6s gecikme
3. İçerik kartları: Scroll'da fade in
```

### Hover Efektleri
```
Service Card:
  Normal → Hover
  ↓
  translateY(0) → translateY(-10px)
  box-shadow: light → box-shadow: strong blue
  gradient-line: hidden → visible

Button:
  Normal → Hover
  ↓
  #e74c3c → #c0392b
  translateY(0) → translateY(-2px)
  shadow: 0.4 → 0.6
```

### Scroll Efektleri
```
Header:
  Top → Scrolled
  ↓
  normal → .scrolled class
  (Ek stil uygulanabilir)

Back to Top Button:
  0-300px: hidden
  300px+: visible (fade in)
  Click: Smooth scroll to top
```

## 🚀 Performans

### Optimize Edilmiş Yapı
```
✓ Tek CSS dosyası (minify edilebilir)
✓ Tek JS dosyası (minify edilebilir)
✓ Harici bağımlılık yok
✓ Font system font kullanımı
✓ Optimized images (lazy-load ready)
✓ Clean code yapısı
```

### Yükleme Sırası
```
1. HTML parse
2. style.css load
3. DOM ready
4. scripts.js load ve execute
5. Images lazy load (opsiyonel)
```
